# ESP32 CYD 4.0-inch ST7796 port

This target is maintained on the `cyd40-st7796` branch and is based on the
GhostESP `Development-deki` branch that was current when the port was started.

## Hardware profile

| Function | GPIO |
| --- | ---: |
| TFT MISO | 12 |
| TFT MOSI | 13 |
| TFT SCLK | 14 |
| TFT CS | 15 |
| TFT DC | 2 |
| TFT reset | not connected |
| TFT backlight | 27 |
| XPT2046 touch CS | 33 |
| XPT2046 touch IRQ | 36 |
| SD CS | 5 |
| SD SCLK | 18 |
| SD MISO | 19 |
| SD MOSI | 23 |

The display is 320x480 in portrait orientation. Touch uses the XPT2046
controller and shares the TFT SPI signals, with its own chip-select line.

## Build target

The target name is `CYD40_ST7796` and its configuration is
`configs/sdkconfig.CYD40_ST7796`. It uses the ESP32 toolchain and the existing
4 MB `partitions.csv` layout. Do not flash this profile until the generated
image has been built and the connected board's flash size and serial port have
been read back.
